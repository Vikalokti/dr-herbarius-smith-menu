# Настройка админки меню

Админка открывается по адресу `/admin/`. Позиции и фотографии хранятся в GitHub, а редактор работает только с формами меню. Для редактора не требуется доступ к репозиторию.

## Первичное подключение

1. Создать сайт в [Decap Turbo](https://turbo.decapcms.org/) из учётной записи человека, который будет вести меню.
2. Подключить GitHub и установить приложение Decap Turbo только на репозиторий `Vikalokti/dr-herbarius-smith-menu`. Владелец репозитория должен подтвердить установку.
3. При создании сайта указать репозиторий, ветку `main`, путь к настройкам `admin/config.yml` и адрес админки, например `https://menu.drherbarius.com/admin/`.
4. Site ID уже внесён в `admin/config.yml`.
5. После публикации открыть `/admin/` и войти в Turbo.

Каждое сохранение создаёт коммит в `main`. Vercel пересобирает статическое меню командой `npm run build`. При переносе сайта на другой хостинг каталог остаётся в GitHub; нужно будет перенести команду сборки и обновить адрес админки в Decap Turbo.
